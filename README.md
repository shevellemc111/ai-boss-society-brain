# AI Boss Society Brain

Skills from **The AI Boss Society** by Shevelle McPherson, Esq.

## Install (Claude desktop app → Cowork)

1. Open **Customize** in the sidebar, then **Plugins**.
2. Choose **Add marketplace** and paste: `shevellemc111/ai-boss-society-brain`
3. Find **ai-boss-society-brain** and click **Install**.

When new skills are added, open the marketplace and click **Update**.

**Prefer a file?** Download `ai-boss-society-brain.plugin` from the class materials and use the upload option on the Plugins page.

> Plugins work in Cowork and Claude Code, not regular Chat.

See [the plugin README](plugins/ai-boss-society-brain/README.md) for what's included.
